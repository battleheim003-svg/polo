# Vertical Slice

Version `0.2.0` turns the prototype into a playable local cup run:

1. Tutorial screen.
2. Team preparation.
3. Deterministic run map.
4. Match 1 against East Wind.
5. Reward selection.
6. Event or camp branch.
7. Match 2 or elite match against Stoneguard.
8. Reward selection.
9. Market or camp branch.
10. Boss match against Cup Guardians.
11. Run result screen.
12. Save/continue and new run support.

No backend, online systems, ads, payments, or 3D work are included.
