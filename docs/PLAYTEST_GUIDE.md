# Playtest Guide

## Goal

Verify a full local cup run from tutorial to boss result.

## Steps

1. Start the app.
2. Choose `Start Cup Run`.
3. Complete the tutorial.
4. Review lineup and start match.
5. Finish each match and choose one reward.
6. Choose event, camp, or market nodes when available.
7. Reach the Cup Guardians boss.
8. Confirm win/loss result and return to menu.
9. Close and reopen, then use `Continue Run`.

## Pass Criteria

- No parser/runtime crash.
- Match result always has a winner.
- Run map unlocks the next row after each node.
- Save/continue restores current run state.
- Boss result ends the run.
